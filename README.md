# Virtual Insanity Game

Jamiroquaiの名曲「Virtual Insanity」のミュージックビデオをモチーフにしたブラウザサバイバルゲームです。プレイヤー（おじさん）を操作し、四方から迫り来るソファーや椅子などの家具に挟まれないように逃げ続けましょう！

## ゲームの目的

白いタイル張りの（動いているように見える）床の上で、ランダムに出現して一直線に滑ってくる家具を避け、できるだけ長く生き残るのが目的です。
時間が経つにつれて家具のスピードと出現頻度が上がり、難易度が増していきます。

## 操作方法

*   **移動**: `W`, `A`, `S`, `D` キー または **矢印キー**
*   **ルール**:
    *   家具にぶつかると押されてしまいます。
    *   画面外の壁際まで押し出されたり、他の家具との間に「挟まれて逃げ場がなくなる」とゲームオーバー（CRUSHED!）になります。

## 起動方法

このゲームはピュアなHTML5 / JavaScript / CSSで作成されています。特別なインストールは不要です。

1.  このディレクトリでローカルサーバーを起動します。
    ```bash
    python3 -m http.server 8000
    ```
2.  ブラウザで `http://localhost:8000` にアクセスします。
3.  「START SURVIVAL」ボタンを押してゲーム開始！

## 技術スタック

*   **HTML5 Canvas**: ゲームのメイン描画
*   **Vanilla JavaScript (ES6)**: ゲームループ、物理演算、衝突・押し出し判定ロジック
*   **CSS3**: UIのスタイリング
*   **AI生成アセット**: キャラクター、家具、背景テクスチャの画像

## 特徴

*   MVの「滑るような歩き方」を表現するための慣性付き移動システム。
*   床タイルの無限スクロールによる錯視（錯覚）演出。
*   AABB（軸平行境界箱）を用いた矩形衝突判定と、家具によるプレイヤーの強制押し出し処理。
